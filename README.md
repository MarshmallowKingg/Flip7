# Flip 7 Scorecard

A mobile-friendly scorecard for the Flip 7 card game.

**Play:** https://marshmallowkingg.github.io/Flip7/

- Add players and pick a target score (default 200)
- Tap a player to score their hand: number cards, ×2, +2 to +10 modifiers, auto +15 Flip 7 bonus, or Bust
- Leaderboard sortable by seat order, score or A–Z
- Tap any score in History to edit it
- Game saves in your browser, so a refresh won't lose it

Single self-contained `index.html`; no build step.
